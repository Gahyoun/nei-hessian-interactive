The stress Hessian

모든 쌍이 spring 인 network 에서 node 하나를 움직이면 curvature 는 어떻게 바뀌는가. Block Hessian $\mathbf H_{ii}$ 는 언제나 positive semidefinite 인 stiffness $K$ 와, 부호가 tension 으로 정해지는 prestress $S$ 의 합이다.

Model

graph $G$ 의 node 를 평면에 embed 하고, 모든 쌍 $(i,j)$ 를 rest length $\delta_{ij}$ (unweighted shortest-path hop distance) 의 spring 으로 잇는다. energy 는 unweighted stress 다.

$$F(X)=\sum_{i<j}\bigl(d_{ij}-\delta_{ij}\bigr)^2,\qquad d_{ij}=\lVert\mathbf x_i-\mathbf x_j\rVert,\qquad X=(\mathbf x_1,\dots,\mathbf x_N)\in\mathbb R^{2N}.$$

node position 은 metric MDS 로 정한다. classical (Torgerson) MDS 를 initial condition 으로 두고 SMACOF (stress majorization) 와 L-BFGS 로 $F$ 를 줄여 멈춘 점이 terminal, 즉 stress 의 local minimum 이다. constraint $N(N-1)/2$ 개가 degree of freedom $2N-3$ 보다 훨씬 많은 overconstrained framework 라서, 어떤 terminal 에서도 모든 spring 이 rest length 에 있을 수 없다. 남은 stress 가 prestress 다.

node $i$ 하나만 움직이고 나머지를 terminal 에 고정하면 $F$ 는 2차원 slice $F_i(\mathbf x)$ 가 되고, 그 Hessian 이 full $2N\times2N$ Hessian 의 $(i,i)$ block 이다.

$$F_i(\mathbf x)=\sum_{j\ne i}\bigl(\lVert\mathbf x-\mathbf x_j\rVert-\delta_{ij}\bigr)^2+\text{const},\qquad \mathbf H_{ii}=\nabla\nabla^{\mathsf T}F_i=\mathbf J(\nabla F_i).$$

symmetric matrix $\mathbf H_{ii}$ 의 eigenvalue $\lambda_1\le\lambda_2$ 는 principal curvature, eigenvector 는 principal direction 이다. eigenvector $\mathbf v$ 방향으로 $\epsilon$ 만큼 움직이면 $F_i(\mathbf x+\epsilon\mathbf v)=F_i(\mathbf x)+\epsilon\,\nabla F_i\cdot\mathbf v+\tfrac12\lambda\epsilon^2+O(\epsilon^3)$ 이다.

eigenvalue 부호에 따른 local curvature type. stationary point ($\nabla F_i=\mathbf 0$) 가 아닌 곳에서는 그 자리의 curvature type 일 뿐이고, stationary point 에서만 Morse index 가 된다.
typeeigenvaluesat a stationary point
BOWL$0\lt\lambda_1\le\lambda_2$local minimum, index 0
SADDLE$\lambda_1\lt0\lt\lambda_2$saddle point (slice barrier), index 1
DOME$\lambda_1\le\lambda_2\lt0$local maximum, index 2

$K$ and $S$: curvature 는 어디서 오는가

쌍 방향의 unit vector 를 $\mathbf u_{ij}=(\mathbf x_i-\mathbf x_j)/d_{ij}$, projector 를 $P_{ij}=\mathbf u_{ij}\mathbf u_{ij}^{\mathsf T}$ 라 하면 block 은 정확히 두 항으로 나뉜다.

$$\mathbf H_{ii}=\underbrace{2\sum_{j\ne i}P_{ij}}_{K\ \succeq\ 0\ \text{(stiffness)}}\;+\;\underbrace{\sum_{j\ne i}\omega_{ij}\bigl(\mathbf I-P_{ij}\bigr)}_{S\ \text{(prestress)}},\qquad \omega_{ij}=\frac{2\,(d_{ij}-\delta_{ij})}{d_{ij}}.$$

$K$ 는 spring 을 longitudinal 방향으로 늘이는 (material) stiffness 다. 위치와 무관하게 $\operatorname{tr}K=2(N-1)$ 이므로 curvature type 을 정하는 것은 $S$ 다. $\omega_{ij}$ 는 force density (길이당 tension) 로, rigidity theory 의 stress coefficient 와 같은 양이다. $S$ 는 transverse 방향에만 작용하는 geometric (stress) stiffness 로, tension ($\omega\gt0$) 은 transverse 방향을 단단하게, compression ($\omega\lt0$) 은 무르게 만든다. 따라서

$$\operatorname{tr}\mathbf H_{ii}=2(N-1)+\sum_{j\ne i}\omega_{ij},\qquad \text{DOME}\ \Rightarrow\ \sum_{j\ne i}\omega_{ij}\lt-2(N-1).$$

즉 dome 은 그 자리에서 compression 의 force density 합이 고정된 stiffness 합을 넘어설 때만 생긴다. 같은 graph 라도 prestress 의 배치가 terminal 마다 다르므로 curvature map 도 terminal 마다 다르다.

Scope

  • Slice 다. barrier 와 second basin 은 다른 $N-1$ 개 node 를 고정한 conditional 값이다. 모든 node 가 함께 relax 하는 full landscape 의 minimum-energy path 와는 다른 양이며, 다른 좌표가 relax 하면 barrier 는 낮아질 수 있다.
  • Block 판정이다. BOWL / SADDLE / DOME 은 $\mathbf H_{ii}$ 하나에 대한 것이다. terminal 전체의 stability 는 Numbers 표의 $\mathbf H_\perp$ (rigid-body mode 3개를 뺀 $2N-3$ 차원) 로 따로 확인했다.
  • Unweighted stress. graph drawing 에서 흔한 $w_{ij}=\delta_{ij}^{-2}$ weight (Kamada–Kawai 형) 가 아니다. weight 를 넣으면 $K$ 와 $\omega_{ij}$ 에 $w_{ij}$ 가 곱해질 뿐 decomposition 의 형태는 같다.
  • Data. 모두 largest connected component, unweighted. Zachary karate club ($N=34$), Lusseau dolphins ($N=62$), Les Misérables co-appearance ($N=77$), college football ($N=115$), ca-netscience coauthorship ($N=352$).
  • Terminal. classical MDS → SMACOF → L-BFGS, random seed 없음. classical MDS 에서 겹치는 structurally equivalent node 는 $10^{-3}$ 크기의 golden-angle offset 으로 떼어 놓았다.
  • Preset node. 모든 node 의 slice 에서 terminal 이 아닌 basin (grid local minimum 을 BFGS 로 다듬고, minimax path 의 barrier 가 두 minimum 보다 0.05 이상 높은 것) 을 찾아 gain $F_i^{\rm term}-F_i^{\rm basin}$ 이 가장 큰 node 를 골랐다. gain $\gt0$ 이면 slice 안에 terminal 보다 낮은 basin 이 있다. college football 은 모든 slice 가 single basin 이라, $\lambda_1$ 이 가장 작은 (가장 soft 한) node 로 dome region 까지 다녀오는 curvature tour 를 보여 준다. 현상이 잘 보이는 node 를 고른 것이지 random sample 이 아니다.
